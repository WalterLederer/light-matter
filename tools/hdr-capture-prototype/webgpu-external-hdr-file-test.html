WebGPU: externe Bilddatei → FP16-Textur

Wähle eine HDR-Bilddatei, vorzugsweise HDR-AVIF oder ein anderes HDR-Format, das dein Browser dekodieren kann. Das Testprogramm kopiert das dekodierte Bild mit copyExternalImageToTexture in eine rgba16float-Textur und liest ausgewählte Pixel zurück.

Einschränkung: createImageBitmap kann je nach Browser und Format HDR-Metadaten oder Werte in SDR umwandeln. Daher protokolliert dieser Test die tatsächlich im Ziel ankommenden Werte; ein Ergebnis ≤ 1.0 beweist allein nicht, dass der Kopierer HDR abschneidet. Ein positiver Wert über 1.0 ist hingegen ein Hinweis, dass Werte oberhalb SDR erhalten blieben.



Bitte zuerst eine Bilddatei auswählen.
