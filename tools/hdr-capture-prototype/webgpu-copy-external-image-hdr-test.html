WebGPU: copyExternalImageToTexture

Vergleicht einen direkt per Shader erzeugten FP16-Wert 3.0 mit einem SDR-Canvas, das per copyExternalImageToTexture in eine rgba16float-Textur kopiert wird. Beide Zieltexturen werden per GPU-Readback numerisch ausgelesen.

Wichtig: Der Canvas-Pfad ist absichtlich SDR. Der Test prüft den Kopierpfad und den Readback, beweist aber nicht, dass ein echter HDR-Quellwert über 1.0 übernommen wird.
