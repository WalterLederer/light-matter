Measurement logic

Load time: from the start of the image request until the browser fires the load event.

Decode time: duration of the subsequent image.decode() call.

Total time: elapsed wall-clock time from the start of the image request until image.decode() completes successfully.

These measurements are not additive phases. Conversion may already be included in Load time and Total time. Convert time is shown separately for diagnostics and must not be added to Total time.
